# Golden Paths Skill

## Purpose
Guide the composition, iteration, and promotion of TRS Platform golden paths across language, cloud, and runtime combinations.

## When to use
Use for work items that create, extend, or promote a golden path, including template, infrastructure, pipeline, runtime, security, docs, and AI workflow integration concerns.

## Inputs expected from a Plane work item
- Language, cloud, and runtime target
- Required environments and shared platform capabilities
- Security, observability, and compliance gates
- Promotion criteria and rollout scope

## Output contract
- Golden-path composition plan tied to modules
- Delivery-wave positioning and rollout recommendation
- Required dependencies across template, infra, CI/CD, runtime, testing, and docs

## Guardrails
- Reuse platform-approved modules and contracts
- Keep AI workflow steps optional, governed, and customer-configured
- Do not promote a path without tests, security gates, and operational readiness

## Definition of done
- [ ] Language × cloud × runtime target is explicit
- [ ] Required modules and dependencies are mapped
- [ ] Quality gates are defined
- [ ] Promotion criteria are documented
- [ ] Iteration wave is linked to the playbook
